# TechNext - React Shopping Cart

A sleek, responsive, and fully functional Shopping Cart application built with React, Vite, and Tailwind CSS. The project demonstrates core e-commerce functionalities such as browsing products in a grid layout, managing the shopping cart (add, remove, update quantities), and displaying real-time calculations.

## 🚀 Features

- **Product Grid View:** Browse a list of products with their images, names, prices, and categories.
- **Shopping Cart Management:** Easily add items to the cart, increase/decrease quantities, or remove items.
- **Real-time Price Calculation:** Automatically calculates the subtotal, discounts, and total price as the cart updates.
- **Cart Drawer & Page:** Quick access to your cart via a slide-out drawer, along with a dedicated full-page cart view.
- **Responsive UI:** Fully responsive and beautifully designed with Tailwind CSS.

## 🛠️ Installation & Setup

Follow these steps to run the project locally on your machine:

1. **Clone the repository**
   ```bash
   git clone https://github.com/mahmudul58/React-Shopping-Cart.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd React-Shopping-Cart/my-app
   ```
   *(Note: Adjust the path depending on where the `package.json` file is located)*

3. **Install the dependencies**
   ```bash
   npm install
   ```

4. **Start the development server**
   ```bash
   npm run dev
   ```
   The application should now be running on `http://localhost:5173/` (or the port specified in your terminal).
